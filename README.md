# 🚀 Space Defender - Ultra Edition

Um jogo de nave arcade frenético desenvolvido inteiramente com HTML5, CSS3 e JavaScript puro (Vanilla JS). Sobreviva a ondas de inimigos, enfrente chefões épicos e alcance o maior placar possível!

## ✨ Funcionalidades

- **8 Mundos e Chefões Diferentes:** Progressão de dificuldade e padrões de ataque únicos.
- **10 Níveis de Armas:** Faça upgrades coletando power-ups durante a batalha (Tiros duplos, laser, plasma, fusão, ômega).
- **Sistema de Combo:** Abates rápidos multiplicam sua pontuação e geram textos animados na tela.
- **Web Audio API:** Efeitos sonoros gerados nativamente por sintetizadores do navegador (sem necessidade de carregar arquivos `.mp3`).
- **Local Storage API:** O seu maior placar (High Score) fica salvo automaticamente e não é perdido ao recarregar a página.
- **Imersão Mobile:** Suporte a Tela Cheia (Fullscreen API) e vibração do dispositivo ao receber dano ou derrotar chefões (Vibration API).

## 🎮 Como Jogar

**Controles:**
- `W, A, S, D` ou `Setas`: Movimentar a nave
- `Espaço` ou `Clique do Mouse`: Atirar (Mantenha pressionado)

**Objetivo:**
Desvie dos tiros, destrua os inimigos para ganhar pontos e colete os itens `↑` para melhorar sua arma. Cuidado: qualquer dano recebido reseta sua arma de volta para o Nível 1!

## 🛠️ Tecnologias Utilizadas

- **Front-end:** HTML5 (Engine de renderização via `<canvas>`), CSS3
- **Lógica:** JavaScript (ES6+)
- **APIs Nativas da Web:** `Web Audio`, `Local Storage`, `Fullscreen`, `Vibration`
